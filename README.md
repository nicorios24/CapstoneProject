# CapstoneProject
NFL analytics capstone project using machine learning to predict game outcomes and player performance.

## Project Overview

This project develops a machine learning-based NFL analytics platform. The initial model uses NFL play-by-play data to predict game outcomes. Future development will expand the project to include player performance and player prop predictions.

## Current Model

The current model is a neural network implemented in R using torch and luz.

The model uses NFL statistics including:

- EPA per play
- Success rate
- Yards per play
- Turnovers

## Data

NFL play-by-play and schedule data are obtained using nflreadr.

The current experiment uses NFL data from 2020-2025.

## Requirements

- R
- torch
- luz
- tidyverse
- nflreadr
- ggplot2
- nflplotR

## Reproducing the Current Experiment

1. Clone this repository.
2. Open the project in R/RStudio/Positron.
3. Install the required R packages.
4. Run the R scripts in the `R/` directory.
5. The model trains on NFL game data and produces game win
   predictions.
6. Prediction results and visualizations are generated by the
   analysis scripts.
